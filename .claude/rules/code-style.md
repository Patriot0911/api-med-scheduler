# Стиль коду

- **Коментарі — лише ситуативно.** Нуль коментарів за замовчуванням, і JSDoc теж: прості методи, DTO, моделі, entity-поля, mapper-и, очевидні перевірки не коментуються. Коментар доречний лише для неочевидного бізнес-правила чи справді складної логіки (`/** A head who leaves the department stops being its head */`) і для заголовка міграції. Не переказуй назви. Рясні коментарі в наявному коді — не зразок.
- Одинарні лапки, `trailingComma: all`; кома після останнього елемента навіть в однорядкових об'єктах: `{ where: { id, }, }`. Старі файли з подвійними лапками масово не переформатовувати.
- Імпорти між модулями — абсолютні від `src/` (`'src/modules/auth/guards/permission.guard'`), всередині модуля — відносні.
- Методи сервісів `async` з явним `Promise<IModel>`; сервіси приймають і повертають інтерфейси з `models/`, не DTO й не entity.
- Без `any` у новому коді.
- Винятки Nest (`BadRequestException`, `ForbiddenException`, `NotFoundException`) з англійським повідомленням для кінцевого користувача, що пояснює правило.
- «Має існувати» — `findOneOrFail` (→ 404 `Not found`); конкретне повідомлення — `findOne` + власний виняток.
- Назви модулів і шляхи імпорту перевіряй (`semester`, `lesson` — однина), не вгадуй.
