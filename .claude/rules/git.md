# Git

- **AI never commits or pushes.** No `git commit`, `git commit --amend`, `git push`, `git tag`, `git merge`, `git rebase`, `git reset --hard`, `git stash drop`, `git checkout -- <file>` / `git restore` over the user's changes. Even when asked to "commit" — provide the commit message as text; the user makes the commit.
- Do not stage (`git add`) unless explicitly asked.
- Reading is allowed: `git status`, `git diff`, `git log`, `git show`, `git blame`.
- Changes stay in the working tree; list the changed files at the end of the task.
