# Git

- **ШІ ніколи не комітить і не пушить.** Жодних `git commit`, `git commit --amend`, `git push`, `git tag`, `git merge`, `git rebase`, `git reset --hard`, `git stash drop`, `git checkout -- <file>` / `git restore` поверх змін користувача. Навіть якщо попросили «закоміть» — підготуй повідомлення коміту текстом, коміт робить користувач.
- Не індексувати (`git add`) без прямого прохання.
- Читання дозволене: `git status`, `git diff`, `git log`, `git show`, `git blame`.
- Зміни лишаються в робочому дереві; наприкінці задачі перелічи змінені файли.
