# Зміна контракту API

Два незалежні репозиторії: `api-med-scheduler` і `../front-med-scheduler`. Контракт = усе, що бачить клієнт: шлях і метод, query-параметри, тіло, поля відповіді, коди помилок і їх сенс (404 vs 403), ліміти (`ArrayMaxSize`, `Min`), значення enum, дозволи на ендпоінті.

## 1. Порядок

1. **Правило** — `docs/domain.md` (сутність, таблиця доступу, фільтр, «Карта ендпоінтів» з позначками 🔓 / 🔑 / дозволами).
2. **Бекенд** — models → DTO → mapper → сервіс → контролер (`nest-module-anatomy`).
3. **Фронт** у тій самій задачі:

| Змінилось на бекенді | Файли фронту |
|---|---|
| модель відповіді / payload | `src/interfaces/<domain>/*.ts` |
| шлях, метод, query | `src/lib/services/<x>.service.ts` |
| новий / змінений фільтр занять | `ILessonsFilters`, `EMPTY_LESSONS_FILTERS`, `lessons.json` (uk, en), `useLessonsFilterOptions`, `LESSONS_VIEWS` |
| ліміт валідації | zod-схема форми (`*.scheme.ts`) |
| enum | дзеркальний enum в `interfaces/` |
| `Permission` | `interfaces/auth/permission.ts`, `configs/permissions.config.ts`, `permissions.json` |
| дозволи ендпоінту | набори `READ_PERMISSIONS` / `MANAGE_PERMISSIONS` у секції й `sidebar.config.ts` (фронт додає `ADMIN` сам) |
| прапорець рішення (`canEdit`, `canManage`) | тип + місце, що блокує дію |
| що відображає мутація | карта інвалідації в мутаційному хуку |

4. **CLAUDE.md** обох репозиторіїв — якщо змінилась поведінка, описана там.

Фронтенд-процедура детально — скіл `frontend-api-resource` у `../front-med-scheduler/.claude/skills/`.

## 2. Сумісність

- Перейменування / видалення поля ламає фронт одразу: міняй обидва репозиторії разом, без «перехідних» дублікатів, якщо користувач не просить інакше.
- Нове обов'язкове поле запиту — або дефолт на бекенді, або фронт оновлюється в тій самій задачі.
- Обгортка `{ status, data }` і формат помилок `{ status: false, message }` не змінюються.
- Повідомлення помилок — англійською (фронт показує їх як є).

## 3. Перевірка

- Бекенд: `npx tsc --noEmit -p tsconfig.json` (**не** `npm run build` — ламає `nest --watch` користувача).
- Фронт: `npx tsc --noEmit` у `../front-med-scheduler` (ловить і відсутні ключі перекладу).
- Живу перевірку роби на вже запущеному dev-сервері (порт 3001) або Swagger `/api/docs`.
